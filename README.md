## 🗂 Folder Structure

```
portfolio/
├── components/          # React components (Navbar, Hero, Projects, Skills...)
├── public/              # Static assets (images)
├── App.tsx              # Main app entry
├── constants.ts         # ← All content lives here (projects, experience, skills)
├── types.ts             # TypeScript type definitions
├── index.tsx            # Root render
└── index.html           # HTML entry point
```

> **To update content:** Only edit `constants.ts` — all projects, experience, and skills are defined there.

## 🚀 Run Locally

```bash
# Clone the repo
git clone https://github.com/nirmalkumarmurali/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Opens at `http://localhost:3000`

---

## 📦 Build for Production

```bash
npm run build
```
